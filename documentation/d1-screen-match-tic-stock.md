## Workflow now in the database
Indent (Draft → Awaiting approval → Sent → Accepted → In transit → Received; Reverted, Rejected, Cancelled) · GIN (Draft → Awaiting approval → Approved → In transit → Received; Reverted, Rejected, Cancelled) · Gate Pass (Issued → Exited → Received; Cancelled) · GRN of a GIN (per-tyre accept / reject).
Stock effect: sender's live stock reduces when the Gate Pass is made; the receiver's live stock increases when it accepts the GRN; a cancelled gate pass returns the tyres.
Capabilities added: `stock.indent` (Tyre IC), `stock.approve` (Supervisor). A Tyre Man sees none of these documents.
